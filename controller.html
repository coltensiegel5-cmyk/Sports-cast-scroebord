OBS Browser Source setup

  1. Copy the scoreboard-only link.
  2. Open OBS Studio → Sources → + → Browser.
  3. Paste the link into the URL box.
  4. Set Browser Source Width = 1280 and Height = 220. The scoreboard automatically fits inside these dimensions; do not crop or stretch it.
  5. Click OK. Right-click the browser source → Transform → Reset Transform if an older crop or stretch is still applied, then move it to the desired spot.

Keep the Sportscast server running while streaming. The link is view-only; it cannot change your scoreboard.
