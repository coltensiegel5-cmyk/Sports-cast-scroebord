OBS Browser Source setup

  1. Copy the scoreboard-only link.
  2. Open OBS Studio → Sources → + → Browser.
  3. Paste the link into the URL box.
  4. Set width to 1280 and height to 220.
  5. Click OK and move your scoreboard wherever you want on the stream.
