SPORTSCAST STUDIO — FULL-WIDTH CONTROLLER UPDATE

What changed
- Uses the full available browser width (no more 1,190px limit).
- Enlarges the controller preview and makes panels more spacious on desktop.
- Adds a Full Screen button to the top bar, plus Exit Full Screen.
- Keeps NFL, College Football, NBC/ESPN/FOX scoreboards, touchdown animations, timeout slots, and game controls.
- No change to the OBS-only view or server authentication.

HOW TO PUBLISH
1. Open https://github.com/coltensiegel5-cmyk/Sports-cast-scroebord/upload/main
2. Upload controller.html from this ZIP; choose to replace the existing file.
3. Click Commit changes.
4. Render will automatically deploy the updated controller.
5. If you still see the old page, refresh with Command + Shift + R.

Full Screen button is in the top header. Press Esc to exit browser fullscreen.
